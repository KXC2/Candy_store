# 🍭 Candy Store — Responsive UI

A simple, responsive candy store webpage created to demonstrate **HTML, CSS, and responsive user interface design**.

The project focuses primarily on the visual presentation and user interaction rather than complex functionality.

## ✨ Features

* Responsive candy store layout
* Product cards displaying different candy products
* Interactive hover effects
* Product prices are revealed when hovering over a product
* Clean and simple user interface
* Designed to work across different screen sizes

## 🛠️ Technologies Used

* **HTML5** — Page structure and content
* **CSS3** — Styling, responsive layout, animations, and hover effects

## 🎯 Project Purpose

This project was created as a **UI/UX and responsive web design exercise**.

The goal was to practice creating a visually appealing webpage that responds to different screen sizes while incorporating simple user interactions through CSS.

Although the application does not contain complex functionality or a backend, it demonstrates the ability to create a structured and responsive interface using fundamental web technologies.

## 🚀 Getting Started

No installation or additional dependencies are required.

Simply open the HTML file in a web browser and interact with the page.

### Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open the HTML file in your preferred web browser.
4. Hover over the candy products to view their prices.

That's it! 🍬

## 📱 Responsive Design

The webpage is designed to adapt to different screen sizes, including:

* 📱 Mobile devices
